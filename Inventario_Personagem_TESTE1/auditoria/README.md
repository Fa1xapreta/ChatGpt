Ferramentas de auditoria da sessão. Os caminhos apontam para os arquivos originais enviados e para os catálogos locais; não são um instalador nem um SDK portátil. O patch usa bytecode existente, sem alegar compilação UCC. A validação nativa usa Unicorn 2.1.4 e pefile; a validação de dados usa o esquema ct0 de acmi/xdat_editor_schema (GPLv3). Os relatórios na raiz são os resultados efetivamente executados.
